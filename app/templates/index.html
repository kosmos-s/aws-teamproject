이 탭을 보고 있지 않을 때 새 메시지가 오면 알림을 띄웁니다. 메시지 내용은 알림에 표시하지 않습니다.

채팅 알람

보고 있지 않은 채팅방에 새 메시지가 오면 누가 보냈는지 알려줍니다. 팝업을 누르면 그 방이 열립니다.

사용 방법

처음 쓰는 멤버와 관리자를 위한 짧은 안내입니다. 화면 왼쪽 메뉴에서 각 기능으로 이동합니다.

처음 로그인

  1. 관리자에게 받은 아이디와 임시 비밀번호로 로그인합니다.
  2. 본인만 아는 새 비밀번호(8자 이상)로 바꾸면 워크스페이스가 열립니다.
  3. 비밀번호는 내 계정에서 언제든 바꿀 수 있습니다. 바꾸면 다른 기기의 로그인은 끊깁니다.

함께 일하기

  • 팀 채팅: # 전체 채팅은 모든 멤버, # 그룹은 소속 그룹, 사람 이름은 1:1 대화입니다. 빨간 숫자는 안 읽은 메시지, ●는 접속 중입니다. 새 메시지가 오면 브라우저 탭 제목에도 숫자가 표시됩니다.
  • 프로젝트: 작업 단위를 만듭니다. 관리자는 끝난 프로젝트를 보관하거나 다시 복원할 수 있습니다.
  • 작업 메모: 진행한 일과 다음 할 일을 남깁니다. 내가 쓴 메모는 수정·삭제할 수 있습니다.
  • 첨부 파일: TXT·PNG·JPG·PDF를 1MiB까지 올립니다. 로그인한 멤버만 내려받을 수 있습니다.
  • 다른 사람이 남긴 내용은 새로고침 없이 약 3초 안에 화면에 나타납니다.
  • 내가 보낸 채팅은 메시지에 마우스를 올려 수정·삭제할 수 있습니다. 내가 올린 첨부 파일도 삭제할 수 있습니다.
  • 새 메시지는 거의 바로 나타나고, 보고 있지 않은 방이면 오른쪽 아래 팝업과 소리로 알려줍니다(내 계정에서 끄고 켬).
  • 한 아이디는 한 곳에서만 접속됩니다. 다른 곳에서 로그인하면 이전 화면의 접속은 끊깁니다.
  • 내 계정 → 브라우저 알림을 켜면 탭을 보고 있지 않을 때 새 메시지 알림을 받습니다.

개발환경 (Orca)

  1. 프로젝트에서 Orca에서 개발환경 열기를 누릅니다(멤버·관리자).
  2. 새 탭의 Orca 사이드바에서 저장소를 골라 파일을 편집하고 터미널을 씁니다.
  3. Orca는 팀이 함께 쓰는 공간입니다. 같은 파일을 동시에 고치지 말고, 개인 작업은 브랜치로 나눕니다.

역할

  • 관리자: 모든 기능 + 멤버·그룹·Orca 연결·서버 관리
  • 멤버: 프로젝트·메모·첨부 작성, Orca 사용, 채팅
  • 게스트(조회): 보기와 채팅만 가능, 쓰기와 Orca는 불가

관리자 안내

  • 멤버 관리: 한 명 추가 또는 여러 명 한 번에 초대(아이디,역할,그룹 한 줄씩). 임시 비밀번호는 한 번만 보이니 안전하게 전달하세요. 역할 변경·차단·비밀번호 재설정·삭제는 각 줄에서 합니다. 자기 계정과 마지막 관리자는 잠글 수 없습니다.
  • 그룹 관리: 팀·부서·기수 그룹을 만들고 멤버 편집으로 사람을 넣습니다. 그룹마다 채팅방이 생깁니다.
  • Orca 연결: 프로젝트를 고르고 방식(GitHub 저장소 받기 / 새 빈 프로젝트 / 서버 폴더 선택)을 정해 요청합니다. 20초 안에 처리되고 결과가 최근 요청에 표시됩니다.
  • 공개 범위: 프로젝트의 '공개 범위'에서 그룹을 고르면 그 그룹과 관리자만 프로젝트·메모·첨부를 볼 수 있습니다. 아무 그룹도 고르지 않으면 모두에게 보입니다. (Orca 서버 자체는 공유 공간이라 폴더 단위 격리는 아닙니다.)
  • 활동 기록: 계정·권한 변경, 콘텐츠 삭제, Orca 연결·접속 기록을 검색합니다.
  • 서버 관리: Webmin으로 서비스와 로그를 확인합니다. Webmin 계정은 포털 계정과 별개입니다.
  • 로그인 실패가 많으면 그 계정이 15분 잠깁니다. 운영 시간이 끝나면 서버가 자동으로 꺼져 접속되지 않습니다.

멤버 관리

역할을 바꾸거나 차단하면 그 사람의 기존 접속이 바로 끊깁니다.
+ 멤버 한 명 추가

첫 로그인 때 본인이 비밀번호를 바꾸도록 요구합니다.

+ 여러 명 한 번에 초대

역할 생략 시 멤버. 그룹이 없으면 새로 만듭니다. 임시 비밀번호는 이 화면에 한 번만 표시됩니다.

그룹 관리

팀·부서·기수 단위로 묶습니다. 그룹마다 전용 채팅방이 생깁니다.

Orca 개발환경 연결

프로젝트를 서버 Orca 작업 폴더와 연결합니다.

GitHub 연동은 선택입니다. 서버 작업이 20초 안에 처리하고, 끝나면 프로젝트에 'Orca에서 개발환경 열기' 버튼이 생깁니다. 비공개 GitHub 저장소는 지원하지 않습니다.
