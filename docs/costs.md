# 비용 확인 — 2026-11-10 (한국 시간)

## 계정에서 직접 확인
- AWS CLI 2.39.3, 프로필 `kosmos-cloud`, 리전 `ap-northeast-2`.
- STS 성공. 인증 파일과 세션 토큰은 저장소에서 제외함.
- Free Tier API: 플랜 FREE / ACTIVE, 잔여 크레딧 **비공개 로컬 비용 기록 참조**.
- 플랜 만료: **비공개 로컬 비용 기록 참조**. API가 반환한 것은 플랜 만료이며 별도 프로모션별 크레딧 만료까지 확인한 것은 아님.
- 기존 서울 기본 VPC·서브넷·인터넷 게이트웨이 재사용. 기존 보안 그룹은 변경하지 않음.

EC2/EBS 단가는 AWS Price List API에서 조회. IPv4 단가는 [AWS VPC 가격](https://aws.amazon.com/vpc/pricing/) 확인.
위 금액은 크레딧 차감 전 정가의 계산이며 청구 확정액이나 강제 지출 상한이 아니다. 데이터 전송·추가 서비스·세금·AI 제공자 사용료는 포함하지 않았다.
추가 유료 CPU 크레딧을 막기 위해 t3를 **standard**로 생성했다. CPU 크레딧 소진 시 성능이 제한될 수 있다.

## 자동 중지와 남는 비용
- 최초 승인 종료: **승인된 시각(로컬 배포 설정 참조)**.
- systemd 절대 시각 타이머 `kosmos-auto-stop.timer`, `Persistent=true`.
- 종료 동작: `shutdown -h now` → EC2의 `InstanceInitiatedShutdownBehavior=stop`.
- 재부팅으로 승인 시간을 연장하지 않는다. 종료 시각을 지난 뒤 다시 부팅하면 타이머가 즉시 중지할 수 있으므로 재사용 때 새 운영 시간 승인이 필요하다.
- 중지 후 t3 실행료와 자동 할당 IPv4 사용료는 멈추지만, **20 GiB EBS 약 $1.82/월은 계속 남는다**.
- 종료/삭제는 별도 사용자 지시 전에는 수행하지 않는다. Terminate는 루트 EBS를 삭제하도록 설정되어 있으므로 백업 없이 실행하지 않는다.
- Free plan을 Paid plan으로 전환하지 않았다. 초기에는 RDS를 만들지 않았으며, 아래 추가 승인 후 포털용 RDS·S3를 생성했다. ALB/NAT/추가 EC2/Elastic IP는 생성하지 않았다.

## 포털 추가 승인과 데이터 절감
2026-11-10 사용자가 RDS·S3 추가 비용과 기존 EC2 종료 시각까지 운영을 승인했다.

| 추가 항목 | 서울 정가 기준 | 월 환산 |
|---|---|---:|
| RDS MySQL db.t4g.micro Single-AZ | $0.025/시간 × 730 | $18.25 |
| RDS 암호화 gp3 20GiB | $0.131/GiB·월 × 20 | $2.62 |
| RDS 합계 | 저장 자동 확장 미설정 | **$20.87** |
| 기존 EC2 구성과 소계 | S3·트래픽·세금 등 별도 | **$45.32** |

RDS는 컴퓨팅과 저장 비용을 합쳐 약 $0.69/일이다. 월 표기는 계속 실행했을 때의 환산이며 실제 운영 기간은 기존 승인 종료 시각까지다.
RDS 중지 요청은 EC2 종료 47초 전의 절대 시각 타이머로 예약했다. 미래 시각의 실제 중지 발생은 미검증이다.
중지 후 RDS 저장 약 $2.62/월, EC2 EBS 약 $1.82/월과 S3 저장 비용이 남는다. RDS는 중지 7일 뒤 자동 재시작될 수 있다.
S3는 공개 접근 차단·AES256이며 backups/는 3일 만료, attachments/에는 만료를 적용하지 않는다. 첨부 1MiB/개와 백업 16MiB/회 제한을 적용했다. 검증 시 S3 객체 4개 합계 2,288바이트였다. 이후 정기 백업으로 바뀔 수 있다.
RDS 자동 백업 보존은 1일이다. 무료 백업 저장 허용량을 무제한 무료로 해석하지 않는다. SSM Standard SecureString으로 새 계정을 암호화 전달했고 일시 IAM 권한을 제거했다. API/KMS 요청 등도 실제 청구에서 확인한다.

## 2026-11-11 고정 IP와 제한 운영
사용자 요청으로 EIP 1개를 기존 EC2에 연결했다. 공인 IPv4 단가는 $0.005/시간으로 기존 실행 중 IP와 같으며 중복 IPv4를 계속 보유하지 않는다. EIP는 EC2 중지 후에도 보유 비용이 남는다(30일 $3.60, 730시간 $3.65). 기존 상시 가동 월 견적 $45.32에는 IPv4 1개가 이미 포함돼 있어 EIP 비용을 중복 가산하지 않는다. 중지 후에는 EBS/RDS 저장/S3와 EIP 비용이 남는다.
현재 승인된 재가동은 오늘 13:47:23 KST까지다. 이후 추가 승인한 ALB/CloudFront는 같은 종료 시각까지 시연 후 정리한다. Route 53 유료 호스팅 영역은 생성하지 않았다. [VPC 공식 가격](https://aws.amazon.com/vpc/pricing/).

## 2026-11-11 강의 시연 추가 검증
사용자 추가 승인으로 ALB와 CloudFront/별도 비공개 S3 OAC를 실제 배포했다. ALB healthy·/health 200, CloudFront Deployed·HTTPS 200, S3 원본 403을 확인했다. 정상 DNS로 포털/Orca 연결, 공개 Orca 터미널 실행과 파일 저장·원본 복구, 로그아웃 후 활성 WebSocket 1008 종료(0.02초)를 검증했다. ALB/CloudFront 시연 자원은 오늘 13:47 종료 후 정리한다. [구성·검증·정리 범위](course-demo.md)

ALB 시연은 약 $0.0225/시간 + 공인 IPv4 2개 약 $0.01/시간 + LCU 사용량이며 부분 시간 과금 기준은 실제 청구에 따른다. 앞서 안내한 30분 $0.02는 시간 비례 추정으로 최종 청구 보장이 아니다. CloudFront/S3 요청·저장·전송 비용은 별도다. 정리 시 CloudFront disable 전파 대기가 남을 수 있으며 삭제 완료를 확인한 뒤 기록한다.
