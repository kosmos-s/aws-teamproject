# 출처와 기여

- Orca: Stably AI의 기존 오픈소스 프로그램. 공식 릴리스 그대로 배포. 자체 IDE/에이전트 엔진 개발로 주장하지 않는다. 배포된 라이선스 내용은 별도 확인 후 제출 소스에 출처와 함께 기재한다.
- AWS CLI / SSM Agent / Session Manager plugin: AWS 제공 관리 도구.
- 팀 작성 범위: 이 프로젝트의 배포 설정, 자동 중지 정책, 접속/검증 스크립트, 비용·구성·검증 문서. 직접 구현한 FastAPI 포털/API·SQLAlchemy 모델·인증/CSRF·첨부 접근 제어·모니터링·논리 백업과 빈 대상 복구를 포함한다. AI 도구의 작성 지원을 받았으며 팀원별 기여는 실제 커밋·검토 기록으로 설명한다.
- 원본 handoff 문서와 `sources/`는 변경하지 않았다.
- 팀 역할(2026-11-11 팀 합의, 사용자 확인): 김건보 — AWS 배포·포털 구현 전반 / 강태영 — 테스트·3인 시연·검증 기록 / 박찬욱 — PPT·발표(전체 발표)·문서 정리. 커밋은 공동 저장소의 한 계정(kosmos-s)으로 기록돼 Git 기록만으로 개인별 기여를 구분할 수 없다.


## 팀 운영 추가 기능 (2026-11-11, 로컬)
[팀 운영 절차](team-operations.md)에 적용 순서와 미적용 항목을 기록했다. 추가 유료 AWS 자원이나 알림 서비스를 생성하지 않았다. 로컬 구현·검증은 운영 배포/메일 발송/2FA 등록과 구분한다.

## 2026-11-11 후속 작업
