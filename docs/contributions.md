# 출처와 기여

- Orca: Stably AI의 기존 오픈소스 프로그램. 공식 릴리스 그대로 배포. 자체 IDE/에이전트 엔진 개발로 주장하지 않는다. 배포된 라이선스 내용은 별도 확인 후 제출 소스에 출처와 함께 기재한다.
- AWS CLI / SSM Agent / Session Manager plugin: AWS 제공 관리 도구.
- 팀 작성 범위: 이 프로젝트의 배포 설정, 자동 중지 정책, 접속/검증 스크립트, 비용·구성·검증 문서. 포털/DB/백업 기능은 구현한 이후에만 기여 목록에 추가한다.
- 원본 handoff 문서와 `sources/`는 변경하지 않았다.
- 팀원별 실제 역할·커밋/검토 기록은 아직 미확정. 제안 역할을 실제 참여 사실로 표시하지 않는다.
