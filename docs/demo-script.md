# 발표와 시연 순서

주제: AWS 기반 팀 공유 AI 개발환경 구축 및 운영. 설치한 Orca와 직접 작성한 포털·운영 코드를 구분한다.

1. 공개 HTTPS 포털에서 인증서를 확인한다. 로그인 전 API/첨부가 거절되는 것을 보여준다.
2. 포털 로그인 후 프로젝트 1개, 메모 1개와 작은 TXT 파일을 등록하고 새로고침해 유지되는지 확인한다.
3. 인증된 다운로드로 원본과 같은 파일이 나오는지 확인한다. 업로드는 1MiB 이하로 제한한다.
4. 매분 점검의 시각과 Orca 고정 포트·CPU/RAM/disk를 확인한다. 오래된 점검은 정상으로 설명하지 않는다.
5. 관리자가 논리 백업을 실행한 뒤 **별도 빈 DB/폴더**로 복원한다. 메모와 첨부 SHA-256을 비교한다.
6. 포털의 Orca 연결 버튼으로 공개 HTTPS Orca에 접속해 aws-teamproject를 선택하고 예제 코드를 편집·실행한다. 운영자의 SSM 경로는 별도로 유지한다. AI 로그인은 보류 중이므로 AI 실행 성공으로 설명하지 않는다.
7. 자동 중지 예약, 중지 후 저장 비용, RDS의 7일 후 자동 재시작 가능성을 설명한다.

검증 상태는 docs/verification.md와 STATUS.md에 따르며, 실행하지 않은 3인 동시 접속이나 AI 작업을 성공했다고 표시하지 않는다.
팀 역할 분담은 이번 요청 범위에서 제외했다. 발표에 실제 기여를 추가할 때는 Git 커밋과 작업 기록을 근거로 작성한다.

## 강의 서비스 추가 시연
시연 시간 창 안에서는 CloudFront 정적 안내 → HTTPS 포털 이동, ALB /health 응답, AWS 콘솔의 healthy 대상·비공개 RDS·S3 OAC 정책·EIP 연결을 보여준다. 정적 S3 원본은 익명 403, ALB 로그인 경로는 404임을 확인한다. 종료 후 새 시연 자원을 삭제하므로 이후 발표에서는 검증 기록과 구성도를 사용하거나 별도 비용/시간 승인 후 재생성한다. 상세는 [강의 적용 시연](course-demo.md)을 따른다.
