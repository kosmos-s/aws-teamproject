# 팀 운영 기능 실행 계획
사용자가 추천 항목 전체 구현을 요청했다. 현재 서버 재시작·원격 변경 없이 로컬에서 구현하고 시험한다.
1. 계정 관리: 관리자만 계정 생성/역할/비활성화/세션 회수. viewer는 조회만, member는 Orca, admin은 Webmin 관리. 자기 계정 잠금과 마지막 관리자 제거를 거절. 기존 users 열을 바꾸지 않고 차단 테이블 도입.
2. CI: push/PR에서 고정 의존성으로 전체 unittest, Python/셸 문법 검사. 원격 Actions 활성화 실행은 미수행.
3. 코드 백업: 운영자 CLI에서 Git 추적 파일만 아카이브, 비밀 경로·symlink·용량 제한, 빈 별도 폴더에 안전 복원 후 바이트 비교. 고정 프로젝트 경로는 관리 환경에서 지정.
4. 외부 장애 알림: EC2 밖에서 실행할 CLI와 타이머. 연속 실패 후 알림, 상태 변화만 전송, 예정 중지와 운영 시간 밖에는 억제. 수신처는 환경 변수. 현재 외부 발송 없음.
5. 비용/정리 화면: 운영 시간·자원/보관 상태 수동 동기화 JSON을 관리자만 조회. 미조회는 unknown, 견적과 실제 청구 구분. 삭제/시작 웹 API 없음.
6. Webmin 2FA: 현재 버전과 공식 도구에 맞는 TOTP 등록·복구·검증 절차 및 로컬 사전 점검. 사용자의 인증 앱 등록 없이는 활성화 완료로 표시하지 않음.
Review focus: 권한 우회, 세션 회수, 마지막 관리자, archive traversal/symlink/secret 포함, 알림 중복·수신처/운영 시간 누락, 비용 상태를 임의 정상으로 표시.


진행 결과: 계정/권한·UI·CI·코드 백업/복구·외부 감시·운영 현황 화면 로컬 구현. Webmin 2FA는 실제 등록 전 사전 점검/절차까지 준비. 전체 39개 로컬 테스트와 관리자/조회 전용 브라우저 확인. 서버/원격 저장소/메일은 변경하지 않음.
검토 수정: 캡처한 Git commit으로 tree 고정, 생성 경로·DB sidecar·Windows 우회 경로 거부. 각각 실패 회귀 테스트 후 통과. 검증 오류의 비밀번호 입력 반사를 공통 422 처리로 제거.
남은 적용: 새 서버 운영 시간/로그인 확인 후 배포, GitHub push/CI 확인, 외부 감시 호스트/SMTP 수신처 구성·실제 통지, 사용자 TOTP 등록. 기존 AI 로그인·3인/Orca 파일 저장·코드 복구의 AWS 검증도 별도다.
